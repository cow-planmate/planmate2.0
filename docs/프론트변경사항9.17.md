# PlanMate 웹 프론트 변경 사항

기준 커밋: `5983d99` — 일정 정보 모달 UI 수정

## 챗봇

- 장소 추천 목록에서는 주소를 바로 노출하지 않도록 변경했습니다.
- 추천 장소에 설명이 있는 경우 간단한 소개를 표시합니다.
- 추천 장소의 `자세히` 버튼을 누르면 장소 상세 정보를 확인할 수 있습니다.
- 장소명이나 답변에 포함된 `**강조 문구**`가 마크다운 기호 그대로 보이지 않고 굵은 글씨로 표시됩니다.
- 챗봇 기본 창 크기를 키웠습니다.
- PC에서는 챗봇 창의 왼쪽 테두리, 위쪽 테두리, 왼쪽 위 모서리를 드래그해 크기를 조절할 수 있습니다.
- 챗봇 버튼과 창을 화면 오른쪽으로 이동했습니다.

## 일정 생성 및 편집

- 시간표에 배치된 장소 블록에 상세 정보 버튼을 추가했습니다.
- 상세 정보 버튼을 누르면 해당 장소의 상세 모달을 열 수 있습니다.
- 장소 블록의 상세 정보, 메모 수정, 삭제 버튼이 블록 드래그·크기 조절과 겹치지 않도록 동작을 보완했습니다.
- 블록 높이 변경 튜토리얼의 장소 블록을 실제 시간표 블록과 같은 모양과 가로폭으로 변경했습니다.
- 튜토리얼 블록의 색상, 시간 정보, 아이콘과 상·하단 조절 표시도 실제 편집 화면에 맞췄습니다.
- 비로그인 상태에서는 지도 기능을 열 수 없으며, 로그인 후 이용할 수 있다는 안내가 표시됩니다.

## 사용법 및 체크리스트

- 사용법과 체크리스트 관련 버튼을 화면 왼쪽으로 이동했습니다.
- 체크리스트 패널도 화면 왼쪽에서 열리도록 변경했습니다.
- 체크리스트 준비 현황 안내가 사용법 버튼 뒤에 가려지지 않고 버튼 위에 표시되도록 수정했습니다.

## 최근 일정 편집

- 사용자가 직전에 작업하던 일정으로 돌아갈 수 있는 `최근 일정 편집` 버튼을 추가했습니다.
- 버튼은 PC 내비게이션 오른쪽의 닉네임 왼쪽에 표시됩니다.
- 버튼에 마우스를 올리면 직전에 작업하던 일정 이름이 포함된 안내 말풍선이 표시됩니다.
- 모바일 햄버거 메뉴에서도 최근 일정 이름을 확인하고 편집 화면으로 돌아갈 수 있습니다.
- 임시 일정을 폐기하거나 로그아웃하면 최근 일정 정보도 함께 정리됩니다.

## 내비게이션 및 모바일 메뉴

- 모바일 햄버거 메뉴를 PC의 마이페이지 메뉴와 비슷한 간결한 드롭다운 형태로 변경했습니다.
- 큰 아이콘과 설명 중심의 메뉴를 작은 텍스트 메뉴 중심으로 단순화했습니다.
- 모바일 메뉴의 `여행기 피드`를 `여행기`로 변경했습니다.
- 일정 생성 메뉴의 명칭을 `일정생성`으로 통일했습니다.
- 모바일 메뉴에서 `소셜`과 `피드백 보내기` 항목을 제거했습니다.
- 마이페이지의 프로필, 여행 일정 및 캘린더, 커뮤니티 활동 메뉴를 바로 확인할 수 있도록 구성했습니다.
- 메뉴 바깥 영역을 누르거나 다른 페이지로 이동하거나 `Esc` 키를 누르면 메뉴가 닫힙니다.

## 로그인 및 프로필

- SNS 로그인에서 네이버 로그인을 제거하고 Google 로그인만 유지했습니다.
- 프로필의 성별 선택 항목을 남성과 여성으로 정리했습니다.

## 커뮤니티 모바일 화면

- PC의 `지금 뜨는 글` 카드 디자인은 기존 형태를 유지합니다.
- 모바일에서는 큰 인기글 카드가 세로로 쌓이지 않도록 한 줄 가로 스크롤 형태로 변경했습니다.
- 모바일 인기글에는 불꽃 아이콘, 순위, 한 줄 제목과 추천 수만 간결하게 표시됩니다.
- 인기글 영역이 차지하는 높이를 줄여 검색, 정렬과 게시글 목록을 더 빠르게 확인할 수 있습니다.

## 일정 완료 화면

- 일정 완료 화면에서 `확인` 버튼을 누르면 마이페이지의 여행 일정 및 캘린더 화면으로 바로 이동합니다.
