# 2026-11-12 QA 수정 검증

추적: https://github.com/cow-planmate/planmate2.0/issues/44
백엔드 연계: https://github.com/cow-planmate/Backend-v2/issues/73, https://github.com/cow-planmate/Backend-v2/issues/74

## 변경

- C2: 서버 오류 문구 완전 일치 비교를 HTTP 상태 판정으로 교체. 403/404의 안내·내 일정 복귀, 조회 실패 재시도, 최초 실시간 연결 대기 시간 초과 시 복귀/재연결 제공.
- M6: 개별/일괄 삭제 및 공유 일정 나가기 성공 시 해당 일정의 최근 편집 단축키 제거. 다른 일정·임시 일정의 단축키는 보존. 일괄 나가기는 개별 성공분을 즉시 반영.
- C3/M4 일부: 모바일 상세 장소명을 배지·액션과 다른 행에 배치. 편집 제목과 툴바를 두 행으로 분리하고 시간표 제목의 공간 확보. 플로팅 도구 전체 배치는 후속 확인 대상.
- M5/m21/m28: 캘린더가 6주 전체와 이벤트 행 높이에 맞게 늘어나도록 변경. 바·빈 레인의 축소 및 셀 높이 강제 문제 제거. 연도 선택 범위는 현재 표시 연도를 기준으로 생성하고 일정 바 글자를 11px로 확대.
- M8: 모바일 여행기 작성 버튼을 목록 위 일반 문서 흐름으로 이동. 데스크톱의 플로팅 배치는 유지.
- M2: 닉네임 입력 및 저장 전 2~20자 검증. 백엔드 중복확인에도 같은 제한 적용.
- M3: STOMP 재연결 시 새 SockJS 인스턴스를 생성하고 종료 상태 반영. 잠시 연결이 끊겨도 편집기/대화를 유지하며 제목·시간표 영역은 inert로 잠가 미전송 편집을 방지. 계정·일정별 대화/미리보기를 탭 sessionStorage에 보존하고 미연결 반영 요청을 막아 같은 제안으로 재시도 가능. 서버는 raw-WS 외에 동일 사용자·방의 STOMP 세션도 조회하며 두 전송 모드의 undo 컨텍스트를 설정/정리.
- m2/m3/m4/m23: 이동수단 미설정 폴백, 취향 선택 수·한도 안내 및 aria-pressed, 건너뛴 카테고리의 기존 취향 보존, AI 응답 지연 안내 보정.
- M1 일부: 제공자 인증 실패를 쿼터 초과로 단정하던 안내를 서비스 연결 실패 안내로 정정. 실제 제공자 인증 문제를 해결한 것은 아님.

## 검증

- `npm run build` 프로덕션 빌드 성공. 기존의 큰 번들, 오래된 Browserslist 데이터, SCDream3.otf 경고는 남아 있음.
- `node --test tests/recentPlanSession.test.mjs`: 4개 통과. 최근 일정과 무관한 삭제, 일치하는 삭제, 일괄 삭제/인코딩된 ID, 임시 일정 보존.
- 수정한 JSX의 ESLint: 오류 0. Create2의 기존 effect 의존성 경고 4개는 남아 있음. 기존 설정은 TSX를 검사하지 않으므로 TSX lint 통과로 표현하지 않음.
- 로컬 Chrome/Playwright 컴포넌트 fixture: 390px/1440px 장소명 실측(각 227px/573px), 가로 넘침 없음, 캘린더 내부 세로 스크롤 없음, 2027년 선택 표시.
- 로컬 앱/API 응답 모킹: 403/404/500에서 복귀 버튼과 오류 화면 확인.
- 로컬 편집기/API 모킹: 연결 단절 시 제목·시간표 2개 영역의 inert 잠금, 복구 후 해제, AI 대화창 DOM 유지 확인.
- AI fixture: 새로고침 후 대화/미리보기 복원, 연결이 없을 때 POST 미전송, 재연결 후 동일 제안 1회 반영, 반영 상태 저장, 다른 계정에 대화 미노출 확인.
- 취향 fixture: 6번째 선택의 한도 안내·aria-pressed 유지, 세 카테고리 건너뛰기 후 기존 선택 보존 확인.
- 피드 레이아웃: 390px에서 작성 버튼이 일반 흐름, 1440px에서 fixed인 것 확인. 실서비스 데이터 쓰기는 수행하지 않음.
- 백엔드 `ChatbotApplyServiceTest` 13개 + `NicknameVerificationRequestTest` 5개 통과. STOMP 사용자/방 일치와 거부, raw-WS 기존 동작, undo 컨텍스트 정리, 닉네임 1/2/20/21/24자 및 공백 검증 포함.

브라우저 검증은 로컬 코드와 모킹/컴포넌트 fixture 기반이다. 운영 배포 후 실제 계정으로 삭제·협업·AI 반영을 종단간 재검증해야 한다. 테스트용 fixture는 제품 코드에 포함하지 않는다.

## 열린 항목

C1은 자동 생성 요구사항 결정이 필요하다. 현재 POST /api/plan은 빈 날짜별 시간표 생성 API이며 이 경로에는 AI 호출이 없다. 빈 플랜 생성을 실패로 취급하는 변경은 하지 않았다.

대중교통 제공자의 키/권한/쿼터, 삭제 카드 잔존의 운영 재현, 모바일 플로팅 도구 전체 배치, 그 외 미검증 Minor는 #44에 열린 상태로 남긴다. 기본 공유 정책이나 법적 문구 등은 임의 변경하지 않는다. 원 보고서의 개인정보·계정 상태는 공개 저장소에 올리지 않는다.
